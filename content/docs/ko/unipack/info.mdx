`info` 파일은 UniPack의 메타데이터를 정의합니다.
각 줄은 `key=value` 형식으로 작성하며, 앞뒤 공백은 무시됩니다.
`=`가 없는 줄은 경고 없이 무시됩니다.
같은 키가 두 번 이상 나오면 마지막 값을 사용합니다.
글자 인코딩 규칙은 `keySound`와 같습니다.

## 속성

| Key | Type | 필수 | 설명 |
|-----|------|------|------|
| `title` | string | O | UniPack 제목 |
| `producerName` | string | O | 제작자 이름 |
| `buttonX` | int | O | 가로 버튼 수 (**1~64**. `0`은 경고와 함께 열림) |
| `buttonY` | int | O | 세로 버튼 수 (**1~64**. `0`은 경고와 함께 열림) |
| `chain` | int | O | 체인(뱅크) 수 (**1~24**) |
| `squareButton` | boolean | | 정사각형 버튼 여부 (기본: **true**). 값이 정확히 `true`일 때만 켜지고, 그 밖의 값(`false`, `True`, `1`)은 꺼집니다. |
| `website` | string | | 제작자 웹사이트 URL |

## 예시

```
title=My UniPack
producerName=UniPad
buttonX=8
buttonY=8
chain=4
squareButton=true
website=https://unipad.io
```

## 유효성 검사

- `title`, `producerName`이 비어있으면 경고가 발생합니다.
- `buttonX`, `buttonY`, `chain`이 0이면 경고가 발생합니다.
- `chain`이 1~24 범위를 벗어나면 **로드가 중단**됩니다.
- `buttonX`, `buttonY`가 정수가 아니면(예: `abc`) **로드가 중단**됩니다.
- `buttonX`, `buttonY`가 음수이거나 64보다 크면 **로드가 중단**됩니다.

## 공통 형식 기준

- `buttonX`나 `buttonY` 키가 없으면 크기가 없다는 이유로 팩을 거부합니다. 직접 `0`을 써서 경고와 함께 여는 경우와 다릅니다. 현재 앱들을 이 기준에 맞추고 있습니다.
- `squareButton=false`는 버튼 모양만 바꿉니다. 팩 조명은 계속 재생하며, 누름 불빛은 보통 기본값(keyLED가 있으면 끔, 없으면 켬)을 따릅니다. Android와 iOS도 이에 맞추고 있습니다.
- `website`는 쓴 그대로 보관합니다. 열 때 방식이 없는 주소에는 `https://`를 붙이고, `http://`와 `https://`만 엽니다. 방식 없는 주소도 같게 열도록 지원을 맞추고 있습니다.

압축 파일에서는 포장 폴더와 무관한 파일을 무시하고 팩 하나만 엽니다. 팩이 여러 개면 분명한 이유와 함께 거부하는 것이 기준이며, 웹 가져오기도 이에 맞추고 있습니다.
압축 파일 이름은 올바른 Info-ZIP 유니코드 경로 항목이 있으면 그것을 씁니다. 없으면 유효한 UTF-8을 먼저 읽고, 아니면 UTF-8 표시와 관계없이 CP949로 읽습니다. 잘못된 표시나 추가 경로 항목도 앱마다 같게 읽도록 맞추고 있습니다. 다른 Windows 인코딩은 자동으로 알아내지 않으므로 글자가 깨질 수 있습니다. 새 글과 이름은 UTF-8로 저장하세요.

컴퓨터 키보드로 패드·체인·옵션을 다루는 단축키는 웹에서 제공합니다. Android와 iOS에 같은 단축키가 없어도 팩 재생 기준은 같습니다.
연주를 마치거나 Launchpad를 뽑아도 연결 전의 기기 모드로 되돌리지 않습니다.
