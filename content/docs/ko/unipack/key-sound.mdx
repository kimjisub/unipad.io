`keySound` 파일은 각 버튼에 사운드 파일을 매핑합니다.
한 줄에 하나의 매핑을 작성하며, 공백으로 구분합니다.

## 문법

```
chain  x  y  soundFile  [loop]  [wormhole]
```

| 필드 | Type | 필수 | 설명 |
|------|------|------|------|
| `chain` | int | O | 체인 번호 (1 ~ chain) |
| `x` | int | O | 버튼 X 좌표 (1 ~ buttonX) |
| `y` | int | O | 버튼 Y 좌표 (1 ~ buttonY) |
| `soundFile` | string | O | `sounds/` 폴더 내 파일 경로 |
| `loop` | int | | 반복 설정 (아래 참조) |
| `wormhole` | int | | 버튼을 누르고 100ms 뒤에 전환할 체인 번호 |

### loop 값

`loop` 값은 내부적으로 1을 빼서 저장됩니다.

| 작성 값 | 동작 |
|---------|------|
| 생략 또는 `1` | 한 번 재생 (기본) |
| `0` | 무한 반복 |
| `N` (2 이상) | 모두 N번 재생 |
| `0`보다 작음 | 한 번 재생하며, 손을 떼어도 멈추지 않음 |

## 예시

```
1 1 1 kick.wav
1 2 1 snare.wav
1 3 1 hihat.wav 0
2 1 1 bass.wav 1 3
```

- `1 3 1 hihat.wav 0` — 체인 1, (3,1) 위치에 hihat.wav를 무한 반복 재생
- `2 1 1 bass.wav 1 3` — 체인 2, (1,1) 위치에 bass.wav를 한 번 재생하고, 누르고 100ms 뒤에 체인 3으로 전환 (소리는 계속 재생됨)

## 순환 큐 (다중 매핑)

같은 `chain x y` 좌표에 여러 사운드를 매핑하면, 버튼을 누를 때마다 **순서대로 순환**하며 재생됩니다.

```
1 1 1 sound_a.wav
1 1 1 sound_b.wav
1 1 1 sound_c.wav
```

(1,1) 버튼을 누를 때마다: sound\_a → sound\_b → sound\_c → sound\_a → ... 순서로 재생됩니다.

## 재생 방식

- 버튼에서 손을 떼면 그 누름이 시작한 끝없이 반복하는(`loop` 0) 소리만 멈춥니다. 한 번 또는 N번 재생하는 소리는 끝까지 재생됩니다.
- 같은 체인의 같은 버튼을 다시 누르면 그 버튼의 앞 소리를 멈추고 다음 소리를 시작합니다. 다른 체인의 소리는 같은 좌표여도 겹칠 수 있습니다.
- `wormhole`을 생략하거나 `0`으로 쓰면 체인을 바꾸지 않으며 경고도 없습니다. 음수는 경고와 함께 체인 1로 이동합니다.
- `wormhole`이 팩에 없는 체인을 가리키면 가장 가까운 체인(체인 1 또는 마지막 체인)으로 전환합니다.

공통 재생 기준에는 다음 규칙도 포함됩니다.

- 직접 누른 버튼의 체인 이동은 누른 뒤 100ms에 일어납니다. 기다리는 동안 연주자가 화면·키보드·Launchpad로 체인을 직접 고르면 예약된 이동을 취소하고 고른 체인에 남습니다. 연주 화면을 닫아도 예약된 이동은 취소됩니다. 자동 재생과 불빛의 `chain` 명령은 각각의 동작을 따릅니다.
- 여러 입력이 같은 패드를 누르고 있으면 마지막 입력을 뗄 때까지 무한 반복 소리와 조명을 유지합니다. 체인이 바뀌어도 놓기는 원래 누름을 따릅니다.
- 연주자와 자동 재생의 누름은 각각 자기 소리와 조명을 가집니다. 하나를 놓아도 다른 쪽이 현재 가진 소리나 조명을 끝내면 안 됩니다.

겹치는 입력과 체인 이동 시점은 앱별로 이 기준에 맞추고 있습니다.

## 글자 인코딩

이 규칙은 UniPack의 모든 텍스트 파일(`info`, `keySound`, `keyLED` 안의 파일, `autoPlay`)에 같습니다.

- 먼저 UTF-8로 읽습니다. 맨 앞의 UTF-8 바이트 순서 표시(BOM)는 버립니다.
- 바이트 순서 표시(BOM)로 시작하는 UTF-16(리틀 엔디언, 빅 엔디언)을 읽습니다.
- 둘 다 아니면 CP949(EUC-KR, 한국어 Windows 인코딩)로 읽습니다.

새 파일은 UTF-8로 저장하세요.

<Callout title="유효성 검사">
- 빈 줄과 3개 미만의 컬럼을 가진 줄은 무시됩니다.
- 좌표가 범위를 벗어나면 해당 줄은 건너뛰고 경고가 기록됩니다.
- 참조하는 사운드 파일이 `sounds/` 폴더에 없으면 경고가 기록됩니다.
- 사운드 파일 이름의 대소문자가 `sounds/` 안의 파일과 달라도 찾습니다(대소문자까지 같은 파일이 있으면 그것을 먼저 씁니다). 그래도 이름은 파일과 대소문자까지 같게 쓰세요.
</Callout>

숫자는 ASCII 숫자 `0`–`9`와 선택적인 ASCII 부호 `+`, `-`만 씁니다. 소리 매핑·조명·자동 재생의 숫자는 부호 있는 32비트 정수 범위여야 합니다. 내부에서 1을 뺄 때는 `-2147483649`까지 정확히 보존합니다. 공통 형식은 전각 숫자를 형식 오류로 보며, Android도 이에 맞추고 있습니다.
