앱 업데이트가 맞추는 공통 연주 기준입니다. 목표 동작을 설명하며,
현재 모든 앱 버전과 기기의 검증이 끝났다는 뜻은 아닙니다.

## 중단과 복귀

앱 전환·잠금·연주 화면 가림·웹 탭 숨김·장치 선택·소리 출력 상실에는 곡 시각과 남은 기다림을
멈춥니다. 모든 입력의 누름·소리·진행 중 조명을 해제합니다. 돌아와도 재생을 직접 눌러야
시작하며 권한이나 연결 알림만으로 곡이 시작하지 않습니다. 다음 미처리 명령부터 진행하고
과거 누름은 되살리지 않습니다. 자동 연주·가이드·한 칸 연습 선택은 보존합니다.
팩 종료·앱 재시작에는 재개 예약을 남기지 않습니다. 연주 화면 안의 메뉴 펼치기만으로는 중단하지 않습니다.

## 손가락과 체인

패드 사이 미끄러뜨리기는 저장되는 선택이며 저장값이 없으면 꺼짐입니다. 꺼져 있으면 다른 패드나
빈틈으로 이동해도 처음 누른 패드를 손을 뗄 때까지 유지합니다. 켜져 있으면 이전 패드를 놓고
새로 들어간 패드를 누릅니다. 빈틈·영역 밖에서는 해제합니다. 여러 손가락은 독립입니다.
취소·회전·가림·설정 변경에는 현재 누름을 정리하며 아직 내려온 손가락을 새 누름으로 되살리지 않습니다.

화면 체인은 누르는 순간 한 번 바뀝니다. 손을 떼기 전에 친 패드도 새 체인입니다. 떼거나 취소해도
이전 체인으로 돌아가지 않으며 체인 위를 끌어 여러 체인을 연속 선택하지 않습니다.
`keySound`의 직접 체인 선택에 따른 예약 이동 취소 규칙도 유지합니다.

## 마지막 기다림

자동 연주는 마지막 `delay`까지 지킵니다. `on 1 1` 다음 `delay 2000`이면 곡 시각 2000밀리초에
끝나고 자동 연주가 잡은 누름만 놓습니다. 다른 손의 누름을 빼앗지 않습니다. 마지막 기다림 중
일시정지하면 남은 시간도 멈춥니다. 수동 정지·팩 종료는 즉시 정리합니다.
유한 소리와 조명은 각자의 기존 종료 규칙을 따르며 새 꼬리 시간을 붙이지 않습니다.

## 시작 선택과 조명

누름 불빛은 팩 진입과 자동 연주 종료 때 팩에 조명이 있으면 끄고 없으면 켭니다. 연주 중 직접
바꾼 선택은 그 구간에 적용합니다. 워터마크는 마지막 명시적 선택을 앱 재시작에도 기억하며
선택이 없으면 켜짐입니다. 팩을 열어도 사용자가 낮춘 음량을 올리지 않습니다. 모바일 시스템
음량을 웹 저장 음량으로 덮지 않습니다. 웹은 저장값을 읽은 뒤 재생할 수 있고 값이 없으면
기존 7단계 중 7을 유지합니다. 같은 숫자가 같은 실제 음압이라는 보장은 하지 않습니다.

팩 조명을 끄면 진행·대기·반복·미전달 조명을 모두 버리고 화면과 장치 불빛을 정리합니다.
꺼진 동안 새 조명을 쌓지 않으며 켠 뒤에는 새 입력의 조명만 시작합니다. 소리와 자동 연주 진행은
유지합니다. 누름 불빛과 워터마크는 별도 선택입니다.

## 자동 맞춤·백업·복원

자동 맞춤은 명시적 실행 때만 팩을 바꿉니다. 첫 누름 앞에는 1000밀리초를 둡니다. 누름 앞의
연속 기다림은 하나로 합쳐 그 앞 마지막 누름의 소리 길이로 바꿉니다. 기다림 없는 연속 누름은
동시 누름으로 유지하고 체인 순서·소리 순번을 보존합니다. 마지막 누름 뒤 기다림은 버립니다.
길이를 읽지 못하면 원래 기다림을 유지합니다. 음수가 아닌 밀리초는 가장 가까운 정수로
반올림하고 정확히 반이면 올립니다. 400.4는 400, 400.5는 401입니다. 결과는 `touch` 또는 같은
시각 누름·놓기 한 쌍이며 무한 누름을 남기지 않습니다.

새 결과와 직전 자료를 함께 안전하게 저장한 뒤에만 완료를 알립니다. 재시작해도 둘을 보존하고
복원은 현재 자료와 직전 백업을 교환하므로 다시 되돌릴 수 있습니다. 재차 맞추면 직전 상태를
새 백업으로 남깁니다. 저장 공간 부족·중단이면 원본과 백업을 보존하고 실패를 알립니다.
웹은 원래 압축 파일을 보존하고 브라우저 팩 자료에 결과와 백업을 저장합니다. 디스크에서 파일을
열었다는 이유로 몰래 원본을 덮어쓰지 않습니다. 저장 중 중복 실행·복원을 막고 연주를 멈춥니다.

## 흔적

연주 화면에 새로 들어가면 비어 있고 기록은 꺼짐입니다. 숫자가 기본이며 기존에 저장한 숫자·선·점
선택은 유지합니다. 기록을 끄면 새 기록만 멈추고 기존 흔적은 남습니다. 다시 켜면 이어 기록합니다.
체인별 순서·반복 번호는 표시 방식·프로 라이트·화면 재배치에도 보존합니다. 지우기는 전체 체인을
비우되 기록 켜짐·꺼짐 선택은 그대로 둡니다. 길게 눌러 지우기와 연주 메뉴의 별도 모두 지우기를
함께 제공합니다. 팩을 종료하면 흔적을 비웁니다.

## 소리 한도와 실패

정확한 정수 기준은 [소리 파일](sounds)을 따릅니다. 파일 자료 판정·실제 해독·출력·기기 메모리는
서로 다른 확인입니다. 자료 판정 통과만으로 같은 잘린 재생 길이·실제 재생·실물 장치·최고 메모리까지
보장하지 않습니다.
