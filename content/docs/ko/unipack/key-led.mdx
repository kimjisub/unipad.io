`keyLED` 폴더에는 LED 애니메이션 파일을 저장합니다.
각 파일은 특정 버튼을 눌렀을 때 실행될 LED 시퀀스를 정의합니다.

## 파일명 규칙

파일명 자체가 매핑 정보를 담고 있으며, **공백으로 구분**합니다.

```
chain x y [loop]
```

| 필드 | 설명 |
|------|------|
| `chain` | 체인 번호 (1 ~ chain) |
| `x` | 버튼 X 좌표 (1 ~ buttonX) |
| `y` | 버튼 Y 좌표 (1 ~ buttonY) |
| `loop` | 반복 횟수 (기본: 1, `0` = 무한 반복) |

### 예시 파일명

```
keyLED/
├── 1 1 1          → 체인 1, (1,1), 1회 실행
├── 1 1 1 0        → 체인 1, (1,1), 무한 반복
├── 1 2 3 2        → 체인 1, (2,3), 2회 반복
└── 2 1 1          → 체인 2, (1,1), 1회 실행
```

같은 좌표에 여러 파일을 매핑하면 `keySound`와 마찬가지로 순환 큐로 동작합니다.

파일 이름을 유니코드 조합형(NFC)으로 맞추고 소문자로 바꾼 뒤 UTF-16 코드 단위 순서로 정렬합니다. 한글 자모나 결합 문자를 분리해서 적어도 같은 글자를 합쳐 적었을 때와 순서가 같습니다. 파일을 열 때는 원래 이름을 그대로 사용합니다.

## 이벤트 문법

파일 내부에 LED 이벤트를 한 줄에 하나씩 작성합니다. 공백으로 구분합니다.
글자 인코딩 규칙은 `keySound`와 같습니다.

### `on` — LED 켜기

```
on x y color [velocity]
on x y auto velocity
```

약어: `o`

| 필드 | 설명 |
|------|------|
| `x` | LED X 좌표, `*` / `mc` (체인 라운드 LED), 또는 `l` (로고 LED) |
| `y` | LED Y 좌표. `l`이면 빼거나 그 자리에 `0` 같은 자리 값을 씁니다. `a`·`auto`는 안 됩니다(특수 좌표 참고) |
| `color` | 6자리 HEX 색상 (예: `FF0000`) 또는 `auto` / `a` |
| `velocity` | MIDI velocity (0~127), `auto`일 때 필수 |

#### 색상 지정 방식

| 형식 | 예시 | 동작 |
|------|------|------|
| HEX만 | `on 1 1 FF0000` | 앱에서 빨간색으로 표시 |
| HEX + velocity | `on 1 1 FF0000 5` | 앱에서 빨간색, Launchpad에 velocity 5 전송 |
| auto + velocity | `on 1 1 auto 72` | velocity 72에 매핑된 Launchpad 팔레트 색상 사용 |

#### 특수 좌표

| 토큰 | 의미 |
|------|------|
| `*` 또는 `mc` | Launchpad 상단/측면의 라운드(체인) LED |
| `l` | 로고 LED. `y`를 뺄 수 있습니다: `on l FF0000`, `on l auto 72`, `off l`. 또는 `y` 자리에 `0` 같은 자리 값을 둘 수 있습니다: `on l 0 FF0000`, `on l 0 FF0000 5`, `on l 0 auto 72`. 자리 값으로 `a`·`auto`는 쓰지 마세요: `on l a FF0000`은 velocity가 `FF0000`인 자동 색으로 읽혀 그 줄은 버려집니다. HEX 색과 함께 velocity를 보내려면 `y` 자리에 값을 두세요: 값이 없으면 `on l FF0000 5`는 `5`를 색으로 읽습니다(`000005`, 거의 검은색). |

### `off` — LED 끄기

```
off x y
```

약어: `f`. `x` 위치에 `*` / `mc` 또는 `l`을 사용할 수 있습니다.

### `delay` — 대기

```
delay ms
```

약어: `d`. 다음 이벤트까지 지정된 밀리초만큼 대기합니다. `delay 0`은 기다리지 않습니다.

### `chain` — 체인 전환

```
chain chainNumber
```

약어: `c`. LED 시퀀스 실행 중 체인을 전환합니다.
팩에 없는 체인 번호이면 가장 가까운 체인(체인 1 또는 마지막 체인)으로 전환합니다.

## 전체 예시

파일명: `1 3 2 0` (체인 1, 좌표 (3,2), 무한 반복)

```
on 3 2 FF0000
on 3 3 00B8D4
delay 100
off 3 2
off 3 3
delay 50
on * 1 auto 72
delay 100
off * 1
```

## 재생 방식

- 버튼에서 손을 떼면 끝없이 반복하는(`loop` 0) 애니메이션은 바로 멈추고, 그 애니메이션이 켠 LED가 꺼집니다.
- 한 번 또는 N번 실행하는 애니메이션은 손을 떼도 끝까지 실행됩니다.
- 애니메이션이 실행되는 중에 같은 버튼을 다시 누르면, 앞 애니메이션의 LED를 끄고 그 버튼의 다음 애니메이션을 처음부터 시작합니다.

<Callout title="유효성 검사">
- 파일명의 좌표가 범위를 벗어나면 해당 파일은 무시됩니다.
- `on` 명령에는 반드시 `color` (4토큰) 또는 `auto` + `velocity` (5토큰)를 지정해야 합니다.
  `y`를 뺀 로고 줄(`l`)은 예외입니다: `on l FF0000` (3토큰), `on l auto 72` (4토큰)도 맞는 줄입니다.
- 인식할 수 없는 명령어가 있으면 해당 줄은 건너뜁니다.
- 좌표가 패드 격자 밖(0, 음수, `buttonX` / `buttonY`보다 큼)인 `on`, `off` 줄은 경고 없이 남겨 두고, 애니메이션을 실행할 때 그 줄만 건너뜁니다. 같은 파일의 다른 줄은 그대로 실행됩니다.
- `loop`이 음수이면 경고가 기록됩니다.
</Callout>

## 색과 놓기 규칙

색은 ASCII 16진수 한 자리부터 여섯 자리까지 씁니다. 뒤에 속도값이 없는 `a`는 거의 검은색인 `00000A`입니다. `on l a`와 `on * 1 a`도 같습니다. 속도값이 빠진 자동 색 명령이 아닙니다. `on l a FF0000`에서는 `a`가 자동 색을 뜻하고 `FF0000`이 잘못된 속도값이 됩니다. 로고에 16진수 색을 쓰려면 `on l FF0000`이나 `on l 0 FF0000`으로 쓰세요.
16진수 색만 쓰면 Launchpad에는 속도값 **4**를 보내므로 기기 색은 앱의 RGB 색과 다를 수 있습니다.
칸 수가 틀린 줄은 원형 불빛 번호의 범위를 확인하기 전에 형식 경고를 남깁니다(`o mc 99` 포함). Android와 웹도 이 경고 순서에 맞추고 있습니다.
무한 반복 조명은 체인이 바뀌어도 원래 누름을 놓을 때 끝납니다. 여러 입력은 마지막 입력을 놓을 때까지 유지하고, 연주자와 자동 재생은 자기 애니메이션을 따로 가집니다. 놓기 동작도 앱별로 이 기준에 맞추고 있습니다.
