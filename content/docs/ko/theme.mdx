UniPad의 테마 시스템을 사용하면 연주 화면의 외관을 커스터마이징할 수 있습니다.
ZIP 파일로 배포되며, 버튼, 배경, 체인 영역의 이미지와 UI 색상을 변경할 수 있습니다.
같은 테마 ZIP을 Android 앱, iOS 앱, [웹 플레이어](/play)에서 쓸 수 있습니다. 앱마다 다른 점은 각 항목에 적어 두었습니다.

## 파일 구조

```
my-theme.zip
├── theme.json          (필수)  테마 이름·제작자
├── theme_ic.png        (권장)  테마 목록 아이콘
├── playbg.png          배경 이미지
├── btn.png             패드 버튼 (기본 상태)
├── btn_.png            패드 버튼 (눌린 상태)
├── phantom.png         가이드 오버레이
├── phantom_.png        가이드 오버레이 변형 (선택)
├── custom_logo.png     화면 오른쪽 위 로고 (선택)
├── logo_led.png        프로 라이트 모드 로고 칸 (선택, 다음 Android 버전부터)
├── chainled.png        체인 LED 모드 이미지 (모드 A)
├── chain.png           체인 기본 상태 (모드 B)
├── chain_.png          체인 선택 상태 (모드 B)
├── chain__.png         체인 가이드 상태 (모드 B)
└── colors.json         UI 색상 커스터마이징 (선택)
```

`theme.json` 말고는 모두 빼도 됩니다. 파일 이름은 위와 똑같이 소문자로 쓰세요.

## 테마 정보

### theme.json

테마의 이름, 제작자, 버전 정보를 담은 JSON 파일입니다. ZIP에 꼭 있어야 하는 유일한 파일입니다.

```json
{
  "name": "My Theme",
  "author": "Your Name",
  "version": "1.0.0"
}
```

| 필드 | Type | 필수 | 설명 |
|------|------|------|------|
| `name` | string | O | 테마 표시 이름 |
| `author` | string | O | 제작자 이름 |
| `version` | string | O | 버전 문자열 (예: `"1.0.0"`) |

세 필드를 항상 모두 넣으세요. 하나라도 빠졌을 때 앱마다 다르게 동작합니다.

- **iOS 앱**: `theme.json`이 올바른 JSON이 아니거나 `name`·`author`·`version` 중 하나라도 빠지면 가져오기에 실패합니다. `version`도 지금은 꼭 있어야 합니다.
- **Android 앱**: `version`이 빠지면 `"1.0"`으로 채웁니다. `theme.json`이 올바른 JSON이 아니거나 `name`·`author`가 빠지면 가져오기가 끝나도 테마 목록에 나타나지 않습니다.
- **웹 플레이어**: `name`·`author`가 빠지면 `Unknown`, `version`이 빠지면 `"1.0"`으로 채웁니다. `theme.json`이 없거나 올바른 JSON이 아니면 기본 테마와 같은 이름(`Default`, 제작자 `UniPad`)으로 목록에 보입니다.

### theme\_ic.png

테마 선택 목록에 표시되는 아이콘입니다. 44dp 크기로 렌더링되며 모서리가 둥글게 처리됩니다.
없어도 테마를 가져올 수 있으며, 그때는 기본 테마 아이콘이 표시됩니다.

- 권장 크기: 132×132px (xxhdpi)
- 정사각형 이미지 권장
- 아이콘은 `.png`로 넣으세요. Android 테마 목록은 `theme_ic.png`만 읽습니다.

## 이미지 리소스

**PNG 포맷**을 권장합니다. Android 앱과 웹 플레이어는 같은 이름의 WebP, JPG, JPEG 파일도 읽지만(PNG → WebP → JPG → JPEG 순서로 찾음), iOS 앱은 PNG만 읽습니다(아이콘 `theme_ic.webp`만 예외).
투명한 부분이 필요한 이미지는 PNG로 만드세요.

누락된 리소스는 앱의 기본 테마로 대체됩니다. 예외는 세 가지입니다.

- `phantom_.png`가 없으면 모든 패드에 `phantom.png`를 씁니다.
- `custom_logo.png`가 없으면 로고를 표시하지 않습니다.
- `chainled.png`가 없으면 체인 영역이 모드 B(`chain.png`, `chain_.png`, `chain__.png`)로 바뀝니다. 아래 **체인 영역** 절을 참고하세요.

웹 플레이어는 아직 이 세 예외를 따르지 않고, 빠진 파일 자리에 기본 테마 그림을 씁니다(고치는 중). 테마를 브라우저로 먼저 시험해 볼 때는 Android·iOS 앱에서 다르게 보일 수 있다는 점을 기억하세요.

### 패드 영역

| 파일 | 설명 | 용도 |
|------|------|------|
| `playbg.png` | 연주 화면 전체 배경 | 패드 그리드 뒤에 표시 |
| `btn.png` | 패드 버튼 기본 상태 | 8×8 그리드의 각 패드 |
| `btn_.png` | 패드 버튼 눌린 상태 | 패드를 터치했을 때 |
| `phantom.png` | 가이드 오버레이 | 자동 연주 가이드 등에 사용 |
| `phantom_.png` | 가이드 오버레이 변형 | 짝수 크기 패드에서 2×2 패턴으로 교차 표시 (선택) |
| `custom_logo.png` | 화면 로고 | 연주 화면 오른쪽 위에 표시 (선택) |

### 화면 로고 (custom\_logo.png)

연주 화면 오른쪽 위 구석에 장식으로 표시되는 로고입니다. 그림의 원래 색 그대로 보입니다.

- 가로 약 90dp 크기로 표시되며, 패드나 체인 버튼을 가리게 되면 그만큼 작아집니다.
- 옵션에서 **UI 숨기기**를 켜면 사라집니다.
- 웹 플레이어에서는 줄어들지 않고 항상 가로 90px로 표시되며, 옵션 창이 열려 있는 동안에는 숨겨집니다.
- 넣지 않으면 로고를 표시하지 않습니다.
- 팩의 로고 불빛을 따라 빛나는 로고는 아래의 `logo_led.png`입니다. 두 그림은 서로 대신하지 않습니다.

### 프로 라이트 모드 로고 칸 (logo\_led.png)

<Callout title="지원 범위">
다음 Android 버전부터 적용됩니다. iOS 앱과 웹 플레이어는 아직 이 칸을 그리지 않으므로, 파일을 넣어 두어도 무시됩니다.
</Callout>

옵션에서 **프로 라이트 모드**를 켜면 패드 둘레에 둥근 버튼이 생기고, 위쪽 줄과 오른쪽 줄이 만나는 모서리에 로고 칸이 나타납니다.
실제 Launchpad의 로고 불빛처럼, 팩의 LED 파일이 로고에 보내는 색(`on l auto 5`, `on l FF0000` 등, [LED 문서](/docs/unipack/key-led) 참고)으로 빛납니다.
`logo_led.png`는 이 칸에 그릴 모양을 정합니다. 누를 수 있는 버튼은 아닙니다.

**만드는 법**

- 투명 배경 위에 흰색으로 모양을 그린 **정사각형 PNG** 한 장을 권장합니다. 크기는 **128×128px 이상**, 가장자리 여백은 적게 두세요.
- 앱은 그림의 투명도만 씁니다. 그림의 원래 색은 무시되고, 보이는 부분 전체가 그때의 로고 불빛 색으로 칠해집니다. 반투명한 부분과 부드러운 가장자리는 그대로 남습니다.
- 켜졌을 때와 꺼졌을 때 그림을 따로 만들 필요는 없습니다.

**빛나는 방식**

- 팩이 로고에 색을 보내면 모양 전체가 그 색으로 빛납니다. 예를 들어 `on l auto 5`이면 빨간색입니다.
- 로고 불빛이 꺼지면(`off l`) 또는 옵션의 **Led**가 꺼져 있으면, 모양은 그 테마의 **꺼진 패드 색**으로 보입니다. 이 색은 `btn.png`의 평균 색입니다(완전히 투명한 픽셀은 빼고, 반투명 픽셀은 덜 반영). 무늬가 있는 패드 그림이라도 무늬를 옮기지 않고 평균 색 한 가지로 칠합니다. `btn.png`가 없거나 읽을 수 없거나 전부 투명하면 기본 테마 패드의 색을 씁니다.
- 체인 모드 A와 모드 B 어느 쪽이든 같게 동작합니다.

**크기와 위치**

- 옆에 있는 둥근 버튼의 약 70% 크기 정사각형 안에, 비율을 유지한 채 자르거나 늘리지 않고 맞춰 넣습니다. 그림의 투명한 여백도 그림 크기에 포함됩니다.
- 정사각형이 아닌 그림은 그 정사각형 안에 들어가게 줄어듭니다. 패드 배치가 특이해 자리가 좁으면 버튼을 가리지 않도록 더 작아질 수 있습니다.
- 일반 모드에서는 보이지 않습니다. **UI 숨기기**를 켜도 둥근 버튼과 함께 계속 보입니다.

**넣지 않았을 때**

- 파일이 없거나 읽을 수 없으면 기본 UniPad 로고(네 조각 모양)를 씁니다. 기존 테마는 고치지 않아도 됩니다.
- `custom_logo.png`를 대신 쓰지는 않습니다.
- 투명도가 없는 JPG를 넣으면 사각형 전체가 빛나고, 완전히 투명한 그림을 넣으면 로고 칸이 보이지 않습니다.

```
diamond-theme.zip
├── theme.json
├── theme_ic.png
└── logo_led.png        투명 배경에 흰 마름모를 그린 128×128 PNG
```

이 테마에서는 마름모가 `on l auto 5`에 빨갛게 빛나고, `off l`이면 꺼진 패드 색으로 돌아갑니다.

### 체인 영역

체인 영역은 두 가지 모드 중 하나를 선택합니다.

#### 모드 A: LED 모드

`chainled.png` 파일이 존재할 때 활성화됩니다.
패드 버튼(`btn.png`)을 배경으로 사용하고, `chainled.png`를 팬텀 레이어에 배치한 뒤 LED 색상을 오버레이합니다.

| 파일 | 설명 |
|------|------|
| `chainled.png` | 체인 LED 이미지. LED 색상이 오버레이로 적용됨 |

#### 모드 B: Drawable 모드

`chainled.png` 파일이 없을 때 활성화됩니다.
각 상태별로 서로 다른 이미지를 직접 표시합니다.
웹 플레이어는 아직 `chainled.png`가 없어도 기본 체인 그림으로 모드 A를 그립니다(고치는 중).

| 파일 | 설명 |
|------|------|
| `chain.png` | 체인 기본 상태 / LED 채널 |
| `chain_.png` | 체인 선택 상태 |
| `chain__.png` | 자동 연주 가이드 상태 |

## 색상 커스터마이징

### colors.json

UI 요소의 색상을 변경할 수 있습니다. 모든 필드는 선택이며, 지정하지 않은 필드는 기본 색상을 사용합니다.
색상 값은 따옴표로 감싼 `#RRGGBB` 또는 `#AARRGGBB` 형식의 HEX 문자열로 쓰세요. Android·iOS 앱은 읽지 못하는 문자열을 그 항목만 기본 색상으로 대체합니다. 다른 형식은 앱마다 받아들이는 범위가 다르니(예: Android 앱은 `red` 같은 색 이름도 받음) HEX만 쓰세요.
파일 자체는 올바른 JSON이어야 하고, 색 값은 숫자가 아니라 문자열이어야 합니다. JSON이 깨졌거나 문자열이 아닌 값이 있으면 iOS 앱은 이 파일 전체를 무시하고, Android 앱은 테마를 열지 못하고 기본 테마로 되돌아갑니다. 웹 플레이어는 깨진 파일을 무시하고, 문자열이 아닌 값은 그 항목만 기본 색상으로 둡니다.

```json
{
  "checkbox": "#FF5722",
  "trace_log": "#2196F3",
  "option_window": "#424242",
  "option_window_checkbox": "#FF9800"
}
```

| 필드 | 설명 |
|------|------|
| `checkbox` | 옵션 체크박스 색상 |
| `trace_log` | **흔적 기록** 옵션이 패드 위에 남기는 숫자·선 색상 |
| `option_window` | 옵션 패널 배경 색상 |
| `option_window_checkbox` | 옵션 패널 내부 체크박스 색상 |

웹 플레이어는 지금 `trace_log`와 `option_window_checkbox`만 반영하고, 나머지 두 색은 Android·iOS 앱에서만 바뀝니다.

## 예시

### 최소 구성

```
minimal-theme.zip
└── theme.json
```

`theme.json`에는 `name`·`author`·`version`을 모두 넣으세요. 모든 리소스가 앱 기본 테마로 대체됩니다. 테마 목록에는 이름과 기본 아이콘이 표시됩니다. 아이콘을 보이게 하려면 `theme_ic.png`를 함께 넣으세요.

### 전체 구성

```
full-theme.zip
├── theme.json
├── theme_ic.png
├── colors.json
├── playbg.png
├── btn.png
├── btn_.png
├── phantom.png
├── phantom_.png
├── custom_logo.png
├── logo_led.png
└── chainled.png
```

## 설치 방법

1. 위 구조에 맞게 파일을 준비합니다.
2. 모든 파일을 단일 ZIP 파일로 압축합니다. 파일은 ZIP 루트에 두세요. Android 앱은 하위 폴더 안의 파일을 찾지 않습니다.
3. 앱(Android·iOS)에서 **테마 → 테마 추가 → ZIP 파일 가져오기**를 선택합니다. 웹 플레이어에서는 첫 화면의 **테마** 버튼을 누릅니다.
4. ZIP 파일을 선택하면 자동으로 검증 및 설치됩니다.

## 유효성 검사

Android·iOS 앱에서 쓰려면 다음을 지켜야 합니다.

- `theme.json`이 ZIP 루트에 있어야 합니다. 없으면 테마가 설치되지 않고 오류 메시지가 표시됩니다.
- `theme.json`은 올바른 JSON이어야 하며 `name`, `author`, `version`이 있어야 합니다(`version`은 iOS 앱에서 꼭 필요). 빠졌을 때 앱마다 어떻게 되는지는 위 theme.json 항목을 참고하세요.

`theme_ic.png`를 비롯한 이미지 파일은 검사하지 않습니다. 없거나 읽을 수 없는 이미지는 기본 테마 이미지로 대체됩니다.
웹 플레이어는 검사가 느슨해서 `theme.json`이 없어도 가져오지만, 앱에서도 쓰려면 위 조건을 지키세요.

<Callout title="디자인 팁">
- 이미지에 투명 배경(알파 채널)을 사용하면 LED 색상이 자연스럽게 블렌딩됩니다.
