The `sounds` folder stores sound files referenced by the `keySound` file.

## Supported Formats

| Format | Extension | Notes |
|--------|-----------|-------|
| WAV | `.wav` | Recommended (PCM 16bit) |
| MP3 | `.mp3` | Supported |
| M4A (AAC) | `.m4a` | Supported |
| OGG Vorbis | `.ogg` | The iOS app does **not** play it at present. Use WAV, MP3 or M4A for packs played on iOS. |

A sound is decoded by its content, not its extension: an MP3 saved as `.wav` still plays.

## Example

```
sounds/
├── kick.wav
├── snare.wav
├── hihat.m4a
├── bass.mp3
└── fx/
    └── sweep.wav
```

<Callout title="Notes">
- Files are referenced by name in `keySound`, so paths and names must match exactly.
- Subdirectories are supported (e.g., `fx/sweep.wav`).
- For compatibility, use only **alphanumeric characters, hyphens, and underscores** in file names.
- At least **30 sounds** can play at the same time.
</Callout>
